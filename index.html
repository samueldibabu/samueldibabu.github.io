Selected projects

Data leakage in deep learning for chest X-ray classification

In progress

How much do image-level data splits inflate the reported performance of a chest X-ray classifier compared with patient-level splits?

  • Fine-tuning a pretrained DenseNet-121 on the public NIH ChestX-ray14 dataset (14 thoracic findings).
  • Comparing patient-level and image-level splits with per-finding AUROC and patient-level bootstrap confidence intervals.
  • Using Grad-CAM to check whether model attention falls on clinically relevant anatomy.
Python · PyTorch · DenseNet-121 · Grad-CAM

Predicting in-hospital recurrent myocardial infarction

Team project · 2026

A comparative benchmark of ten machine learning models on 1,700 patients from the UCI Myocardial Infarction Complications dataset, reported following TRIPOD+AI.

  • Nested cross-validation, a held-out test set, 12 metrics with bootstrap 95% CIs, calibration and SHAP explanations.
  • Found that the patient ID alone predicted the outcome (AUC 0.73) because the file was sorted, and that missing-value indicators leaked length of stay.
Python · scikit-learn · SHAP · View on GitHub
